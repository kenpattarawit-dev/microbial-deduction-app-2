# คำนวณหักเงินจากผลเพาะเชื้อ (Microbial Plating Deduction App)

โปรแกรมคำนวณหักเงินจากผลเพาะเชื้อ Glove Print และ Personal Monitoring (Contact Plate) ในห้องสะอาดโรงงานผลิตยา
ประมวลผลฝั่งเบราว์เซอร์ 100% (Client-Side) ปลอดภัย ไม่ส่งข้อมูลออกภายนอก

## คุณสมบัติ
- อ่านและเขียนไฟล์ Excel ด้วย SheetJS (`xlsx`)
- คำนวณยอดหักเงินรายคนรายวันอัตโนมัติ (เกินเกณฑ์ > 5 CFU หัก 10 บาท/คน/วัน)
- แจ้งเตือนข้อความที่ไม่ใช่ตัวเลข (เช่น `*13 รา`) พร้อมพิกัดเซลล์
- สรุปตารางรายคนรายวัน พร้อมไฮไลต์สีแดง
- ส่งออกไฟล์สรุปเป็น Excel (`สรุปหักเงิน.xlsx`) มี 2 ชีท (สรุปหักเงิน และ รายละเอียด)
- รองรับทุกอุปกรณ์ (มือถือ, แท็บเล็ต, คอมพิวเตอร์) และรองรับ Dark Mode
- รองรับ PWA สามารถกดติดตั้งเป็นแอปลงบนมือถือหรือคอมพิวเตอร์ได้

## วิธีรันโปรเจกต์ในเครื่อง (Local Setup)

1. แตกไฟล์ ZIP และเปิด Terminal / Command Prompt ในโฟลเดอร์โปรเจกต์
2. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
3. รันโปรเจกต์:
   ```bash
   npm run dev
   ```
4. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## วิธีนำขึ้น GitHub & Deploy บน Vercel ฟรี

1. สร้าง Repository บน [GitHub](https://github.com/)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub
3. เข้า [Vercel](https://vercel.com/) เลือก **Add New Project** ➡️ เลือก Repository ที่เพิ่งสร้าง ➡️ กด **Deploy**
